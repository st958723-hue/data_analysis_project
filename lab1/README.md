# Лабораторная работа №1
## Тема: Архитектура и обучение глубоких нейронных сетей

### Используемые библиотеки:
* **TensorFlow / Keras** — построение, компиляция и обучение модели глубокой нейросети.
* **Matplotlib** — визуализация первых элементов обучающей выборки.
* **NumPy** — предобработка массивов и объединение данных.

### Описание данных:
В проекте используется встроенный набор данных **MNIST** (база данных рукописных цифр). Датасет автоматически разделен на:
* Обучающую выборку (`X_train`, `y_train`) — 60 000 объектов.
* Тестовую выборку (`X_test`, `y_test`) — 10 000 объектов.
* Размерность каждого изображения составляет 28x28 пикселей
